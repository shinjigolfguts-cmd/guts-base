## 公開方法
このフォルダーの中身をリポジトリ直下へアップロード。Settings → Pages → Deploy from a branch → main → / (root) → Save。

## 引き継ぎ範囲
デザイン・掲載内容・ブラウザー内の検索と比較機能を保持。元サイトは変更していません。サーバー処理とGUTS DESKへのアクセス計測は含みません。掲載内容は自動更新されません。お気に入りはブラウザー・サイト別の保存です。

掲載情報は移行元を引き継いでおり、今回の移行で施設や商品情報を再調査したものではありません。
